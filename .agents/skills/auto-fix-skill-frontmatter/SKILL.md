# Навык: Автоматическое исправление frontmatter

## 🎯 Назначение
Автоматически сканирует все `SKILL.md`‑файлы в каталоге `C:\Users\onela\AppData\Local\AI-TC\.agents\skills`,
- заключает строку `description:` в двойные кавычки, если она не заключена;
- добавляет/обновляет строку `Updated: YYYY-MM-DD HH:MM:SS` сразу после первой границы `---`.

## 🚀 Триггеры и применение
Запускается вручную через `manage_tools.py` или другим навыком, когда необходимо обеспечить корректный парсинг YAML‑frontmatter после изменения навыков.

## ⚙️ Протокол выполнения
1. Обход всех поддиректорий `*.agents/skills/*`.
2. Для каждого найденного `SKILL.md` применяются правила из `fix_frontmatter.py`.
3. По завершении выводится список исправленных файлов.

## 📂 Реализация
Скрипт находится в файле `fix_frontmatter.py` в той же директории.

## 🧪 Тестирование
Запуск `python -m auto-fix-skill-frontmatter.fix_frontmatter` в корне проекта должен пройти без ошибок и отобразить список обработанных файлов.

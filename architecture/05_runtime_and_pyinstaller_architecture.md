# Архитектура автономного выполнения (Native Python & PyInstaller)

## 1. Замена PowerShell-скриптов нативный main.py
Для обеспечения возможности сборки приложения в единый исполняемый файл  через PyInstaller вся стартовая логика перенесена из  скриптов в :
- Освобождение портов: прямое завершение конфликтных процессов через .
- Изоляция окружения: проверка  для определения базовой директории.

## 2. Разделение временных и внешних путей
При работе из PyInstaller :
- ** ()**: каталог временной распаковки ресурсов (статические файлы WebGUI, локали).
- ** ()**: внешняя директория запуска .

Все изменяемые файлы (, , внешняя копия ) принудительно создаются и сохраняются только в . Файл  автоматически копируется во внешнюю директорию при отсутствии.

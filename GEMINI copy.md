## 🎯 Архитектурные принципы Версии 2.2
1. **SDK-First**: Вся низкоуровневая логика взаимодействия с ОС Windows концентрируется в `apps/windows/sdk/`.
2. **Zero Direct Polling in API**: HTTP-обработчики FastAPI запрашивают данные исключительно из `telemetry.db` или локального кэша, избегая прямого вызова системных команд.
3. **Instant UI Navigation & IndexedDB**: Кнопки переключения вкладок реагируют мгновенно (0-1 мс). При переходе предыдущие сетевые запросы отменяются через `AbortController`. Журналы кэшируются в `IndexedDB` и обновляются только по кнопке `[Обновить]`.
4. **Унифицированный UI Kit & Themes v2.0**: Все элементы используют единую систему CSS-переменных и готовую структуру компонентов.
5. **Интеграция ИИ Модальных Окон (`apps/windows/api/webgui/ai_modal_dialog`)**: Сквозная привязка диалогового ассистента ко всем панелям сканера программ.
6. **Мультиязычность (i18n)**: Полная локализация интерфейса через `web/locales/ru.json` и `en.json`.
7. **1-to-1 Mapping Директорий**: Директории вкладок и роутеров строго сопоставлены (`tab-software-scanner` -> `tab_software_scanner`).

### 🎯 Требование к генерации быстрых вопросов (`suggested_quick_questions`)

В промпт модели обязательным порядком добавляется инструкция:
```
В обязательном порядке сгенерируй от 3 до 4 контекстных уточняющих вопросов, которые системный администратор может захотеть задать по данному объекту.
Вопросы должны быть конкретными, короткими (до 60 символов) и релевантными (например: 'Зачем процессу сетевой порт 135?', 'Безопасно ли завершить процесс?', 'Как проверить цифровую подпись?').
Верни эти вопросы массивом строк в поле `suggested_quick_questions`.
```

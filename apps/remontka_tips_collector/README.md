# Модуль сбора советов (`remontka_collector`)

Автономный Python-модуль для периодического мониторинга и автоматического сохранения полезных инструкций и советов с сайта в формате JSON с гарантированной защитой от дубликатов.

---

## 📁 Структура проекта

```text
remontka_tips_module/
├── remontka_collector/         # Основной пакет модуля
│   ├── __init__.py             # Экспорт главных классов
│   ├── collector.py            # Класс управления сбором (TipsCollector)
│   ├── config.py               # Настройки и константы по умолчанию
│   ├── fetcher.py              # Загрузчик данных по HTTP
│   ├── parser.py               # Парсер RSS XML и очистка HTML
│   └── storage.py              # Загрузка и запись в JSON
├── main.py                     # Точка входа для запуска из командной строки
├── requirements.txt            # Список зависимостей
└── README.md                   # Документация проекта
```

---

## 🛠 Установка зависимостей

Для работы модуля требуется Python версии **3.8+** и библиотека `beautifulsoup4` для очистки описаний от HTML-тегов.

```bash
pip install -r requirements.txt
```

## 🚀 Способы использования

### 1. Запуск из командной строки (CLI)

#### Непрерывный мониторинг (по умолчанию каждые 3600 секунд / 1 час):
```bash
python main.py
```

#### Разовый сбор без циклического ожидания:
```bash
python main.py --once
```

#### Настройка собственного интервала (например, каждые 30 минут):
```bash
python main.py --interval 1800
```

#### Указание собственного файла вывода:
```bash
python main.py -o my_tips.json
```

---

### 2. Использование как Python-модуля в своем коде

Вы можете легко импортировать `TipsCollector` в любой свой проект:

```python
from remontka_collector import TipsCollector

# Инициализация с параметрами по умолчанию
collector = TipsCollector(json_file="my_tips.json")

# 1. Разовый запуск сбора
added_count = collector.collect_once()
print(f"Добавлено новых советов: {added_count}")

# 2. Или запуск периодического мониторинга (интервал в секундах)
# collector.run_periodic(interval_seconds=1800)
```

## 📄 Формат сохраняемого JSON

Все данные сохраняются в кодировке **UTF-8** с отступами в 4 пробела.

Пример содержимого файла `remontka_tips.json`:

```json
[
    {
        "id": "https://example.com/tip-1/",
        "title": "Заголовок полезного совета",
        "description": "Краткое описание и инструкции...",
        "link": "https://example.com/tip-1/",
        "added_at": "2026-10-12 13:45:00"
    }
]
```

---

## 🛡 Защита от повторов

Сборщик считывает уже существующие записи из JSON-файла перед каждым сканированием. В качестве уникального идентификатора используется URL статьи (`link`). Новый совет добавляется только в том случае, если его ссылка отсутствует в базе сохраненных советов.

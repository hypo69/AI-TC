# 🌐 Роутеры внутреннего API Windows (apps/windows/api/routers)

## Описание
Пакет специализированных FastAPI-роутеров подсистемы `AI-Windows-Admin`.

## Список роутеров
- `router_menu.py` — Управление структурой и пунктами меню консоли администратора.
- `router_ninite.py` — Управление развёртыванием и регламентным обновлением Ninite через Task Scheduler.
- `router_log_settings.py` — Просмотр и настройка каналов журналов событий Windows (wevtapi).
- `router_power_lifecycle.py` — Управление сессиями, гибернацией и питанием.
- `router_chat.py` — Чат-ассистент и взаимодействие с моделями ИИ.
- `router_telemetry.py` — Потоковая телеметрия и аппаратные датчики.
- `router_keys.py` — Управление API-ключами.
- `router_scenarios.py` — Сценарии автоматизации.
- `router_diagnostics.py` — Службы диагностики.

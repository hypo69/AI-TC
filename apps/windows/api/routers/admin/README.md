# Подпакет `admin`

Эндпойнты администрирования, вынесенные из монолитного `router_admin.py` (этап 4 оптимизации).

| Модуль | Назначение |
|---|---|
| `routers.py` | Общие объекты `APIRouter` (`router`, `router_apps`, `skills_router`, `plugins_router`, `windows_users_router`) |
| `instructions.py` | Инструкции, системные промпты, источники |
| `plugins.py` | Менеджер плагинов |
| `apps.py` | Статус и конфигурация приложений `/apps` |
| `rag_search.py` | Конфигурация RAG и веб-поиска |
| `users.py` | Пользователи администрирования |
| `skills.py` | Навыки агента |
| `schedulers.py` | Планировщики |
| `windows_users.py` | Пользователи Windows |

Эндпойнты регистрируются на общих роутерах при импорте модулей; порядок импорта задаётся в `../router_admin.py` и совпадает с исходным порядком маршрутов.

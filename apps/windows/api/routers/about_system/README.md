# Подпакет `about_system`

Код панели «О системе», вынесенный из монолитного `router_about_system.py` (этап 4 оптимизации).

| Модуль | Назначение |
|---|---|
| `models.py` | Pydantic-модели запросов и ответов |
| `helpers.py` | Вспомогательные функции (рабочая группа, uptime, бренд CPU, последний снимок) |
| `query_about.py` | Запросы обзора и истории из `telemetry.db` |
| `query_summary.py` | Полная сводка системы |
| `query_diagnostics.py` | Диагностики: накопитель, троттлинг, утечки, дерево железа, бэкап |
| `endpoints_overview.py` | Эндпойнты сводки и диагностик |
| `endpoints_panels.py` | Эндпойнты карточек дашборда |
| `endpoints_system.py` | Эндпойнты изменения параметров системы |

Роутер собирается в `../router_about_system.py:init_router()`, эндпойнты регистрируются функциями `register_*`.

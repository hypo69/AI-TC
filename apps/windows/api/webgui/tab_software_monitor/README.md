# Вкладка «Установленные программы и Мониторинг ПО» (Software Hub)

Консолидированный пользовательский интерфейс управления, мониторинга и глубокого аудита установленного программного обеспечения Windows (Хаб домена Software архитектуры WebGUI).

## 🎯 Назначение и состав панелей

Вкладка объединяет функциональные панели домена программного обеспечения:

1. **Реестр установленных программ (Инвентарь ПО)**:
   - Полный каталог приложений из реестра Windows (`UninstallKey`);
   - Отображение издателей, версий, даты установки и занимаемого объема;
   - Строка тихого удаления (`Quiet UninstallString`);
   - Фильтрация по категориям (Dev, Utilities, System, Office) и экспорт данных в JSON.

2. **Менеджер пакетов ПО (WinGet, MSI, Microsoft Store & Ninite)**:
   - Раздельное отображение и независимые пункты меню для пакетов **WinGet** и **MSI**;
   - Выделенная панель пакетов **WinGet** (winget-cli, проверка доступных обновлений, удаление);
   - Выделенная панель пакетов **MSI** (Windows Installer, реестр, ProductCode, деинсталляция);
   - Выделенная панель приложений **Microsoft Store** (AppX/MSIX/msstore): идентификаторы Store ID, версии, переход в магазин по протоколу `ms-windows-store://` и управление;
   - Проверка наличия свежих релизов и пакетная установка/обновление;
   - Интеграция с автоматическим загрузчиком и планировщиком задач Ninite Updater.

3. **Спящие программы и Сироты (Dormant & Orphans)**:
   - Глубокое сканирование неиспользуемых >90 дней программ;
   - Анализ телеметрии и артефактов `UserAssist` и `Prefetch`;
   - Выявление осиротевших служб, задач планировщика и некорректных записей деинсталлятора;
   - Модальное окно просмотра низкоуровневых свидетельств и PE-артефактов.

4. **Автозапуск программ (Startup Auditor)**:
   - Комплексный аудит всех точек автозагрузки (реестр Run/RunOnce, папки Автозагрузка, службы, IFEO);
   - Контроль состояния элементов (включение / выключение автостарта в один клик);
   - Фиксация снимков телеметрии в SQLite и вычисление дифференциальных изменений конфигурации;
   - ИИ-диагностика назначения и потенциальных рисков автозапуска через языковые модели.

5. **ИИ-аудит прозрачности и рисков ПО (AI Software Transparency Scanner)**:
   - Оценка благонадежности и потенциальных рисков приложений;
   - Инвентаризация каталогов установки, файлов конфигураций и секретов;
   - Анализ активных сетевых доменов и сокетов, используемых программами.

6. **Ресурсоемкие программы**:
   - Анализ процессов с высоким потреблением CPU, оперативной памяти и дискового I/O с кэшированием в IndexedDB.

7. **Конфигурации и сокеты**:
   - Открытые TCP/UDP порты, активные сокеты и аргументы запуска процессов.

## 🔌 Архитектура и интеграция

Модуль декомпозирован на панели с соблюдением стандарта `<= 500` строк функционального кода (`GEMINI.md`):

```text
apps/windows/api/webgui/tab_software_monitor/
├── index.html                  # Разметка субпанелей хаба, верхние метрики и модальные окна
├── main.js                     # Главный оркестратор, экспорт в window.initSoftwareMonitorTab
├── README.md                   # Документация модуля на русском языке
├── common/
│   └── ui_utils.js             # Экранирование HTML, подгрузка скриптов/HTML с дедупликацией
├── panel_subtabs/
│   └── panel.js                # Навигация и переключение между субвкладками, ленивая подгрузка
├── panel_winget/
│   └── panel.js                # Панель пакетов WinGet (winget-cli)
├── panel_msi/
│   └── panel.js                # Панель пакетов MSI (Windows Installer / msiexec)
├── panel_store/
│   └── panel.js                # Панель приложений Microsoft Store (AppX/MSIX/msstore)
├── panel_dormant/
│   └── panel.js                # Сканер спящих программ (>90 дн.), анализ сирот, модалка свидетельств
├── panel_heavy/
│   └── panel.js                # Ресурсоемкие программы (CPU/RAM/IO) с кэшированием в IndexedDB
└── panel_sockets/
    └── panel.js                # Сетевые сокеты и открытые порты с кэшированием в IndexedDB
```

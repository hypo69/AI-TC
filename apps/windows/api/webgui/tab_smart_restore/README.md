# 🛡️ Вкладка «Умное восстановление Windows» (`apps/windows/api/webgui/tab_smart_restore`)

**Status:** ✅ Active  
**Author:** hypo69  
**Version:** 1.0.0  
**Updated:** 2026-10-16 22:52:00  

Интерактивный веб-интерфейс интеллектуального советника точек восстановления Windows (`RestorePointAdvisor`). Модуль предварительно анализирует состояние системы перед созданием точек, исключает дублирование за счет категориальных отпечатков (Fingerprints) и валидирует готовность теневого копирования томов (VSS). Журнал срезов состояний и дельт сохраняется в `%ProgramData%\AI-Windows-Admin\apps\windows\telemetry\logs\state_journal.sqlite`.

---

## 💡 Предварительная проверка (3 ключевых вопроса)

Перед созданием точки восстановления советник дает ответы на три вопроса:

1. **Есть ли смысл создавать точку?**
   Анализируются изменения в системных файлах, реестре, драйверах, службах и установленных программах с момента предыдущей зафиксированной точки.
2. **Не дублирует ли она предыдущую?**
   Сравнивается нормализованный категориальный отпечаток (хеш) существенных системных параметров, а не только дата и текстовое описание.
3. **Достаточно ли данных и условий для восстановления?**
   Проверяется включение защиты системы на системном диске (`Enable-ComputerRestore -Drive 'C:'`), доступность теневого хранилища VSS и свободное дисковое пространство.

## 📊 Категории анализа и значимость

| Категория | Что сравнивается | Значимость |
|---|---|---|
| **Драйверы** | Версии пакетов `pnputil`, новые/удаленные драйверы, сбои PnP | **Высокая (HIGH)** |
| **Системные файлы** | Версии и метаданные критических файлов ядра (`ntoskrnl.exe`, `hal.dll`, `win32k.sys`) | **Высокая (HIGH)** |
| **Службы** | Тип запуска (Start), путь к бинарному файлу (`ImagePath`), тип службы | **Высокая (HIGH)** |
| **Windows Update** | Список установленных накопительных пакетов и хотфиксов (KB) | **Высокая (HIGH)** |
| **Конфигурация загрузки** | Параметры BCD (таймаут, загрузчик по умолчанию), статус WinRE | **Высокая (HIGH)** |
| **Программы** | Установка, удаление и обновление компонентов в реестре `Uninstall` | **Средняя (MEDIUM)** |
| **Реестр** | Системные ветви политик и автозапуска (`Run`, `Policies\System`) | **Средняя (MEDIUM)** |
| **Пользовательские файлы** | Документы, загрузки, рабочий стол | **Исключено из System Restore** |

## ⚙️ Решения советника (Advisor Decisions)

* 🟢 **CREATE (Создать)**: Обнаружены значимые изменения (драйвер, обновление Windows, служба, программа или файл ядра) и условия восстановления соблюдены.
* 🔵 **SKIP (Пропустить)**: Состояние системы полностью совпадает с предыдущей контрольной точкой (дубликат). Создание избыточной копии блокируется.
* 🟡 **MONITOR (Наблюдение)**: Зафиксированы минимальные второстепенные изменения. Событие сохранено в SQLite-журнале, создание точки отложено.
* 🔴 **CLARIFY (Уточнить)**: Защита системы выключена, ошибка VSS либо недостаточно свободного места на диске.

## 🌐 Связанные REST API эндпоинты

* `GET /api/v1/windows-checkpoints/advisor/evaluate?trigger=...` — предварительная оценка целесообразности.
* `POST /api/v1/windows-checkpoints/advisor/create-smart` — умное создание с дедупликацией.
* `GET /api/v1/windows-checkpoints/advisor/journal` — журнал срезов состояний и дельт.
* `GET /api/v1/windows-checkpoints/advisor/readiness` — быстрая проверка условий VSS и защиты диска.
* `POST /api/v1/windows-checkpoints/advisor/explain` — формирование текстового объяснения на естественном языке.

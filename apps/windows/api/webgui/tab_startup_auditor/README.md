# 🚀 Вкладка Startup Auditor (Аудит автозапуска Windows)

Интерактивная панель мониторинга, анализа рисков и управления точками автозапуска Windows с поддержкой AI-диагностики и отслеживания дифференциальных изменений снимков телеметрии.

## Архитектура модулей

```
tab_startup_auditor/
├── index.html                  # Разметка вкладки, фильтров, таблицы и модальных окон
├── main.js                     # Корневой скрипт-оркестратор (инициализация и диспетчеризация)
├── common/
│   └── ui_utils.js             # Утилиты сетевых вызовов (apiFetch), экранирования и бейджей
├── panel_summary/
│   └── panel.js                # Панель показателей здоровья автозагрузки (KPI Health Score, счетчики, рекомендации)
├── panel_table/
│   └── panel.js                # Таблица элементов автозапуска, фильтрация, поиск, переключение статуса (toggle) и вызов AIModalDialog
└── panel_changes_modal/
    └── panel.js                # Модальное окно истории дифференциальных изменений снимков телеметрии
```

> [!NOTE]
> Инспекция и контекстный AI-анализ записей автозапуска выполняются через централизованное универсальное модальное окно ИИ-ассистента (`window.AIModalDialog.show`). Устаревшее модальное окно `sa-entry-detail-modal` и модуль `panel_entry_modal` выведены из эксплуатации.

## Поддерживаемые API эндпоинты
- `GET /api/v1/startup-auditor/audit` — получение полного аудита точек автозапуска
- `POST /api/v1/startup-auditor/refresh` — сбор нового снимка телеметрии и фиксация дельты
- `GET /api/v1/startup-auditor/changes` — история дифференциальных изменений конфигурации
- `POST /api/v1/startup-auditor/toggle` — безопасное включение/отключение элемента
- `POST /api/v1/startup-auditor/explain` — контекстный AI-анализ назначения и уровня риска программы
- `GET /api/v1/startup-auditor/export` — экспорт списка в JSON / CSV

# Вкладка «Потребление ресурсов» (System & Hardware Inspector)

Интерактивная панель мониторинга аппаратной телеметрии, нативных аппаратных сенсоров Windows, потока процессов хоста и AI-диагностики производительности.

## Структура интерфейса

- **Верхняя полоса KPI**: Загрузка CPU (%), оперативная память RAM (GB), видеоускоритель GPU, скорость дискового ввода-вывода Disk I/O (MB/s).
- **Редактор интервалов опроса (config.json)**: Попап-окно для быстрой настройки частоты Live-обновления веб-интерфейса и фоновых интервалов логирования сенсоров (`system_inspector`, `hardware_monitor` и др.) в `config.json`.
- **Панель «Сетевые адаптеры и беспроводная связь»**: Аппаратный мониторинг сетевых интерфейсов (Ethernet, Wi-Fi, Bluetooth), измерение входящего/исходящего трафика (Rx/Tx), утилизации полосы пропускания и спарклайн-графики в реальном времени.
- **Мониторинг изменений файлов**: Наблюдатель файловой системы (Multi-Directory Watcher) на базе Windows API `ReadDirectoryChangesW`.
- **Правая нижняя панель**: **AI Copilot** — эвристический и нейросетевой анализ аномалий и узких мест производительности системы.

> [!NOTE]
> Спецификация оборудования вынесена во вкладку **«О Системе»** (`about_system_tab`), а детальная сетевая активность процессов хоста — во вкладку **«Активность процессов»** (`tab_processes_load_inspector`).

## API эндпоинты

- `GET /api/v1/panel/cpu-load` — детальная загрузка ядер процессора и тактовые частоты.
- `GET /api/v1/panel/gpu-load` — загрузка GPU, видеопамяти и энергопотребление.
- `GET /api/v1/panel/memory-io` — использование оперативной памяти RAM и файла подкачки.
- `GET /api/v1/panel/network-load` — аппаратная нагрузка сетевых адаптеров хоста.
- `GET /api/v1/panel/storage-load` — активность дисковых накопителей и IOPS.
- `GET /api/windows/hardware/sensors` / `GET /api/v1/system/sensors` — сбор сенсоров через нативный стек Windows / WMI / NVIDIA-SMI.
- `GET /api/autolog/config` — получение конфигурации интервалов опроса логгеров из `config.json`.
- `POST /api/autolog/config` — сохранение настроенных интервалов в `config.json` и перезапуск фонового сбора данных.
- `POST /api/v1/system/diagnose` — глубокий AI-аудит производительности.
- `WS /api/v1/system/stream` — WebSocket поток телеметрии в реальном времени.

## Модульная архитектура (директории panel_*)

В соответствии с инженерным стандартом лимита строк (до 500 строк на файл) монолитный `main.js` разделен на изолированные модули:

```
tab_system_inspector/
├── common/
│   └── ui_utils.js         # Общие графические утилиты (SVG графики, слайдеры, бейджи, форматирование)
├── panel_cpu/
│   └── panel.js            # Модуль панели CPU: ядра, частоты, температуры, SVG мульти-осевой график
├── panel_ram/
│   └── panel.js            # Модуль панели RAM: память, Swap, IO чтение/запись, SVG график
├── panel_gpu/
│   └── panel.js            # Модуль панели GPU: мульти-GPU, VRAM, HotSpot, спарклайн
├── panel_network/
│   └── panel.js            # Модуль сетевой панели: адаптеры, Rx/Tx, Wi-Fi, Bluetooth, спарклайн
├── panel_storage/
│   └── panel.js            # Модуль хранилища: NVMe/SSD/HDD, SMART, AIModal интеграция
├── panel_watcher/
│   └── panel.js            # Модуль мониторинга файловой системы (ReadDirectoryChangesW)
├── panel_ai_copilot/
│   └── panel.js            # Модуль запуска AI-диагностики узких мест системы
├── panel_intervals/
│   └── panel.js            # Модуль модального окна настройки интервалов AutoLog в config.json
├── index.html              # Разметка вкладки
└── main.js                 # Корневой оркестратор (импорт панелей, WebSocket, fallback-поллинг)
```

## Механизм Drill-down и скрытые блоки деталей

Каждая аппаратная карточка компонента (CPU, RAM, GPU, Network, Storage) оснащена верхней панелью (`.sys-card-top-banner`) с интерактивным значком **красной дрели** (`.sys-drill-btn`).

- **Клик по панели или дрели (`onclick`)**:
  - В компактном режиме (`sys-compact-mode`) разворачивает скрытый блок деталей карточки (`sys-card-drill-expanded`), открывая соответствующий скрытый `div` с уникальным ID:
    - CPU: `#sys-card-cpu-details` (и вложенный блок ядер `#sys-cpu-details-collapse`)
    - RAM: `#sys-card-ram-details`
    - GPU: `#sys-card-gpu-details-${idx}`
    - Network: `#sys-card-net-details`
    - Storage: `#sys-card-storage-details`
  - Повторный клик сворачивает блок обратно.
  - Кнопка на верхней полосе `#btn-sys-toggle-compact` осуществляет глобальное сворачивание/разворачивание всех скрытых блоков деталей одновременно.

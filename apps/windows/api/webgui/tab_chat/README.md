# Вкладка «Чат с ИИ» (`tab_chat`)

Интерактивный модуль диалога в реальном времени с языковыми моделями через `UnifiedChatModel` и адаптеры провайдеров.

---

## Ключевые возможности
- **ChatGPT-стиль мультисессионности**: Организация диалогов в изолированные сессии с сохранением в `localStorage` и фоновой синхронизацией с сервером.
- **Умное именование сессий**: Автоматическая генерация кратких заголовков на основе первого вопроса пользователя с возможностью ручного переименования.
- **Сворачиваемая боковая панель**: Быстрое скрытие/раскрытие панели сессий для концентрации на диалоге.
- **Режимы вывода ответа**:
  - `text_only` (💬 Только текст): Прямой текстовый инференс.
  - `text_and_voice` (💬+🔊 Текст и голос): Потоковый вывод текста и последующий синтез речи через TTS.
  - `voice_only` (🔊 Только голос): Голосовой ответ с автоматическим воспроизведением.
- **Интеграция с RAG**: Динамический поиск по локальной базе знаний, настройка TOP_K и минимального порога MIN_SCORE.
- **Потоковый вывод (Streaming)**: Асинхронный прием токенов с оптимизацией через `requestAnimationFrame` и рендерингом Markdown.

## Архитектурная модульная структура
Каждый файл строго не превышает лимит в 500 строк функционального кода согласно стандарту `GEMINI.md`:

```
apps/windows/api/webgui/tab_chat/
├── index.html                  # Разметка чата, сайдбара сессий, ленты и панели параметров
├── main.js                     # Оркестратор вкладки (81 строка), экспорт в window.initChatTab
├── style.css                   # Стили диалоговых пузырей, сайдбара и адаптивной верстки
├── README.md                   # Архитектурная документация на русском языке
├── common/
│   └── ui_utils.js             # Парсинг Markdown в HTML, генерация заголовков, константы хранилища
├── panel_sessions/
│   ├── sync.js                 # Сетевая синхронизация сессий с сервером (/api/chat/sessions)
│   └── panel.js                # Управление локальными сессиями, сайдбар, кеш-статус
├── panel_messages/
│   └── panel.js                # Рендеринг истории сообщений, реплики User/Bot, TTS-кнопки
├── panel_input/
│   └── panel.js                # Поле ввода, RAG-тумблер, TOP_K, MIN_SCORE, внешние промпты
└── panel_stream/
    └── panel.js                # Отправка сообщений, потоковый стриминг RAF, обработка ошибок
```

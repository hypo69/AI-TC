# Вкладка редактора конфигурации телеметрии (`tab_telemetry_config`)

**Назначение:** Интерактивный веб-интерфейс для настройки, валидации и сохранения файла конфигурации модуля сбора телеметрии Windows (`%APPDATA%\AI-Windows-Admin\apps\windows\telemetry\config.json`).

---

## 🏗 Архитектура модулей

```
tab_telemetry_config/
├── index.html                  # Разметка вкладки (метаданные, вкладки GUI / Raw JSON, алерты)
├── main.js                     # Корневой скрипт-оркестратор (инициализация, события, синхронизация)
├── common/
│   └── ui_utils.js             # Константы метаданных сенсоров, DOM-хелперы, алерты и плашки ошибок
├── panel_meta/
│   └── panel.js                # Панель метаинформации о файле (путь, время изменения mtime, режим)
├── panel_form/
│   └── panel.js                # Визуальная форма параметров телеметрии, тяжелых коллекторов и таблица сенсоров
├── panel_raw_json/
│   └── panel.js                # Редактор сырого JSON с подсветкой и live-валидацией
└── panel_actions/
    └── panel.js                # Сетевые операции загрузки, сохранения на лету и сброса к default
```

---

## 🎛️ Возможности

1. **Два режима редактирования**:
   - **Визуальный конфигуратор**: Управление интервалами, лимитами процессов, режимами (`minimal`, `hybrid`, `full`), параметрами SQLite БД, тяжелыми коллекторами и индивидуальными сенсорами с удобными переключателями.
   - **Редактор исходного JSON**: Прямое редактирование с подсветкой, live-валидацией синтаксиса, форматированием и копированием в буфер.
2. **Мгновенное применение на лету (Hot Reload)**:
   - Сохраненные изменения сразу же подхватываются процессом телеметрии на следующем тике без перезапуска сервиса.
3. **Безопасность и сброс**:
   - Откат к исходному шаблону настроек по умолчанию одной кнопкой.
   - Защита от повреждения файла при некорректном синтаксисе JSON.

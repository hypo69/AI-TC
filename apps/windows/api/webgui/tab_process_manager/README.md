# Вкладка Диспетчера Процессов (Process Manager)

> [!NOTE]
> **Архитектурный статус модуля**: В рамках консолидации системного мониторинга (сценарий `tc.ps1`, маршрут `/tc`) вкладка `tab-process-manager` перенесена и интегрирована в состав комплексного хаба **Инспектор активности процессов** ([`tab-processes-load-inspector`](../tab_processes_load_inspector/README.md)) как первая суб-панель **Диспетчер процессов и приложений** (`#subpane-proc-manager`).

---

## 📋 Описание функционала

Панель диспетчера процессов Windows предоставляет интерфейс в стиле диспетчера задач (Task Manager):
1. **Категоризация процессов**:
   - `Apps`: Оконные пользовательские приложения с группировкой окон и дочерних процессов.
   - `Background`: Фоновые системные демоны и службы.
   - `Windows`: Внутренние процессы операционной системы Windows.
2. **Метрики ресурсов**:
   - Мгновенная утилизация CPU (%) и накопленная память RAM (Working Set / Private Bytes).
   - Информация об инициаторе запуска (User / SID) и времени старта.
3. **Безопасное администрирование**:
   - Завершение подпроцесса или полного дерева процессов (`killProcess`).
   - Drill-down переход к углубленному анализу инстанса (Process Intelligence Deep Dive).
   - Прямой вызов универсального модального окна ИИ-ассистента `window.AIModalDialog.show` для объяснения назначения процесса и оценки рисков.
   - Модуль расследования повторяющихся сессий PowerShell.

## 🏛 Модульная архитектура (ES6 Modules)

```
tab_process_manager/
├── common/
│   └── ui_utils.js              # Форматирование памяти/CPU, экранирование HTML
├── panel_table/
│   └── panel.js                 # Таблица процессов, группировка, шевроны, завершение процессов
├── panel_modal_telemetry/
│   └── panel.js                 # Загрузка глубокой телеметрии Per-PID (диск, сеть, приватность)
├── panel_modal_ai/
│   ├── panel.js                 # Модальное окно ИИ, системные инструкции, экспертная диагностика
│   └── chat.js                  # Интерактивный диалог и мини-чат с ИИ по процессу
├── index.html                   # Разметка интерфейса и локального модального окна
├── main.js                      # Компактный оркестратор вкладки (<= 500 строк)
└── style.css                    # Стили интерфейса
```

## 🧭 Навигация и Маршрутизация

- **URL в сценарии `tc.ps1`**: `http://127.0.0.1:8001/tc#tab-processes-load-inspector#manager`
- **Обратная совместимость**: Все переходы по URL `#tab-process-manager` или вызовы `switchTab('tab-process-manager')` автоматически перенаправляются ядром навигации (`apps/main.js`, `js/main.js`, `tc.ps1`) на панель `#tab-processes-load-inspector#manager`.

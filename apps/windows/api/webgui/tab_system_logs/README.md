# 📜 Центр системных журналов Windows (`tab_system_logs`)

## Назначение
Вкладка **Центра системных журналов** (`tab_system_logs`) предоставляет мощный комплексный интерфейс для аудита, мониторинга потока событий в реальном времени, анализа аномалий, RAG-поиска по журналам и расследования инцидентов Windows.

---

## Возможности
- **Дерево каналов и источников**: Сканирование всех зарегистрированных журналов Windows EventLog и локальных файлов логов с группировкой по категориям, отображением количества записей и всплывающими подсказками.
- **Потоковый мониторинг (Live & Errors Stream)**: Фильтрация по уровням критичности (Critical, Error, Warning, Information), временным интервалам, кодам Event ID и тексту с мгновенным кешированием в браузере.
- **Интеллектуальный аудит (Smart Digest)**: Автоматическая дедупликация, шаблонизация записей (masked patterns) и выявление аномальных всплесков без расхода токенов LLM.
- **Временная шкала и матрица активности (GitHub Timeline)**: Интерактивная столбчатая гистограмма частоты событий (Pulse) и недельная 7x24 тепловая карта (Heatmap) с детализацией слотов.
- **Каскады инцидентов**: Выявление цепочек связанных ошибок в заданном временном окне и определение предполагаемой первопричины (Root Cause).
- **Динамический RAG-поиск**: Семантический поиск по кластерам и шаблонам логов через TF-IDF/BM25 индекс.
- **Контекстная ИИ-диагностика**: Анализ выбранного события языковой моделью с формированием рекомендаций по устранению сбоя.
- **Экспорт данных**: Выгрузка отфильтрованных событий в форматы JSON и CSV.

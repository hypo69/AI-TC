# 🛡️ Панель Windows Sysadmin & Identity (`tab_windows_admin`)

## Назначение
Вкладка **Windows Sysadmin & Identity** (`tab_windows_admin`) объединяет инструменты системного администрирования операционной системы Windows, управление учетными записями, аудит привилегий, контроль прав доступа ACL, анализ безопасности и телеметрию сессий.

---

## Возможности
- **Сводка и контекст токена**: Метрики хоста, статус домена/Active Directory, уровень целостности текущего процесса (Integrity Level, SeDebugPrivilege).
- **Контроль периферии (Privacy Radar)**: Мониторинг обращений процессов к веб-камере и микрофону в реальном времени.
- **Резервное копирование (Windows Backup)**: Проверка состояния службы File History и ручной запуск архивации.
- **Управление пользователями и сессиями**: Просмотр локальных/доменных учетных записей, фильтрация по признакам (администраторы, скрытые, онлайн), создание и удаление пользователей, отключение активных сессий и просмотр досье через универсальное модальное окно `AIModalDialog`.
- **Группы безопасности**: Иерархия групп, просмотр членов и выявление прав.
- **Журнал событий безопасности (Security Log)**: Фильтрация событий входа (4624/4625), изменений учетных записей, паролей и блокировок (4740).
- **Экспресс-аудит доступа и SAM**: Проверки «Who is Admin?», прав входа службы («SeServiceLogonRight»), RDP-доступа, осиротевших SID и профилей, а также политика паролей SAM.
- **Инспектор процесса по PID**: Построение дерева контекста безопасности (Process, Parent, Account, Groups, Integrity, Privileges, Session).
- **Каталог операций (~180 функций)**: Реестр Win32 API и CLI механизмов управления безопасностью с оценкой риска.
- **Управление ACL и правами доступа**: Просмотр ACE-записей, смена владельца (takeown), выдача прав (icacls), сброс к системным значениям по умолчанию и резервное копирование дампов.

# Вкладка «ИИ-Агенты» (AI Agents Workbench)

## Описание
Вкладка **«ИИ-Агенты»** (`tab_agents`) предоставляет интерактивную среду для создания, конфигурирования, тестирования и отладки автономных ReAct ИИ-агентов, назначения внешних MCP-инструментов/навыков и выполнения пошаговых цепочек рассуждений (Thought -> Action -> Observation).

## Архитектура модулей
Код декомпозирован по панельной структуре (`panel_*`) в соответствии с инженерными стандартами проекта (`GEMINI.md` § 4.4, лимит строк <= 500):

```
tab_agents/
├── index.html                           # Разметка интерфейса и модальных окон
├── main.js                              # Модульный оркестратор вкладки (< 100 строк)
├── README.md                            # Настоящее описание архитектуры на русском языке
├── common/
│   └── ui_utils.js                      # Реактивное состояние, сетевой клиент fetchJson, нотификации
├── panel_grid/
│   └── panel.js                         # Сетка карточек агентов, тулбар фильтрации и счетчиков
├── panel_editor/
│   └── panel.js                         # Модальный редактор параметров, матрица инструментов и шаблоны
├── panel_ai_builder/
│   └── panel.js                         # AI-генератор спецификаций агентов по описанию задачи
└── panel_sandbox/
    └── panel.js                         # Интерактивная песочница и трассировка шагов ReAct
```

## Основные возможности
1. **Сетка и фильтрация агентов**: Разделение по статусам (все, активные, системные, пользовательские), быстрый тумблер активности.
2. **Конструктор агента**: Настройка провайдера и модели, температуры, таймаута, лимита шагов, выбор инструментов из матрицы.
3. **AI Prompt Architect**: Автоматическое проектирование промпта и подбор инструментов на основе текстового описания задачи.
4. **Интерактивный Sandbox**: Запуск диалога с агентом, выполнение внешних инструментов и подробная инспекция шагов решения.

## Интеграция
- Точка входа: `window.initAgentsTab()`
- Редактор: `window.openAgentEditor(agentId, prefillData)`
- Песочница: `window.openAgentSandbox(agentId)`
- Обновление реестра: `window.loadAllAgentsData()`

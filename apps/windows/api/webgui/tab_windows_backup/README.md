# Вкладка «Резервное копирование и данные» (Windows Backup & Storage)

## Описание
Вкладка **«Резервное копирование и данные»** (`tab_windows_backup`) предназначена для комплексного мониторинга защищенности пользовательских данных в среде Windows, управления библиотеками ОС, службы «История файлов» (File History), семантического поиска по архивам (RAG), безопасного переноса каталогов профиля на вторичные физические диски и аудита удалений файлов через теневые копии (VSS) и журнал Security.

## Архитектура модулей
Файлы декомпозированы по панельной архитектуре (`panel_*`) в соответствии с лимитом `<= 500` строк (`GEMINI.md` § 4.4):

```
tab_windows_backup/
├── index.html                           # Разметка вкладки и модальных окон
├── main.js                              # Модульный оркестратор вкладки (< 100 строк)
├── README.md                            # Описание архитектуры на русском языке
├── common/
│   └── ui_utils.js                      # Экранирование HTML, общее состояние, хелперы модалок
├── panel_overview/
│   └── panel.js                         # Индекс готовности (Health Score), статус File History и триггер бэкапа
├── panel_libraries/
│   └── panel.js                         # Управление библиотеками Windows (создание, папки, флаг закрепления)
├── panel_rag/
│   └── panel.js                         # Семантический поиск File History RAG и синхронизация индекса
├── panel_user_folders/
│   └── panel.js                         # Мониторинг пользовательских папок и мастер переноса (Relocate)
└── panel_vss_audit/
    └── panel.js                         # Теневые копии томов (VSS) и аудит удаления файлов (Security 4663/4660)
```

## Основной функционал
1. **Health Score & File History**: Оценка готовности системы архивации по 100-балльной шкале, статус фоновой службы, периодичность создания снимков и политика хранения.
2. **Библиотеки Windows**: Аудит доступности входящих каталогов, быстрое добавление локальных путей и выбор папки сохранения по умолчанию.
3. **File History RAG Search**: Векторный семантический поиск по содержимому сохраненных версий документов в архиве.
4. **Relocation Master**: Безопасный перенос тяжелых системных папок (`Documents`, `Downloads`, `Pictures`, `Videos`, `Desktop`) на другие тома с перерегистрацией путей в реестре `Shell Folders` и `User Shell Folders`.
5. **VSS & Deletion Audit**: Просмотр теневых копий томов VSS, отслеживание инцидентов удаления файлов в реальном времени с детальным AI-анализом процессов и пользователей через `AITableModal`.

## Интеграция
- Точка входа: `window.initWindowsBackupTab()`
- Обновление данных: `window.loadBackupData()`
- Режим скриптов: ES6-модули (`type="module"`).

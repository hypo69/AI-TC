# 💻 Каталог системных команд Windows System32 (`tab_system32_commands`)

**Статус:** ✅ Активен  
**Язык:** Русский  
**Автор:** hypo69  

---

## 📋 Описание

Интерактивная панель каталога штатных утилит и команд операционной системы Windows (директория `System32`), классифицированных по уровням телеметрии AITelemetry Tiers (Observe, Diagnose, Control, Admin, Destructive, Recovery) и слоям Control Plane (CLI, PowerShell, WMI/CIM, COM, Win32 API, ETW, Реестр).
Включает интеллектуальный пульт подбора и безопасного выполнения команд по текстовому описанию задачи.

## 🎛️ Функционал

1. **Каталог штатных средств:** Полнотекстовый поиск по утилитам Windows, категориям, назначению и тегам.
2. **Слои Control Plane:** Сопоставление каждой утилиты с эквивалентами в PowerShell, Win32 API, WMI/CIM и COM.
3. **Инвентаризация хоста:** Сканирование каталога `C:\Windows\System32` на наличие зарегистрированных утилит.
4. **Интеллектуальный пульт:** Ввод задачи на естественном языке, интерпретация намерения языковой моделью, подбор безопасного шаблона команды и отображение результата выполнения в реальном времени.

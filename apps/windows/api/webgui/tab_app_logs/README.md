# Вкладка «Внутренние логи программы» (App Logs Intelligence)

Вкладка клиентского веб-интерфейса модуля `apps/windows/api/webgui/tab_app_logs` предназначена для глубокого анализа, поиска, AI-диагностики первопричин сбоев и потокового мониторинга внутренних журналов работы программы AI-Windows-Admin строго из каталога `%APPDATA%\AI-Windows-Admin\logs`.

## Возможности

1. **Многофайловый селектор логов:**
   - Мгновенное переключение между всеми журналами программы (`log.json`, `info.log`, `debug.log`, `errors.log`, `fastapi.log`, `gemini.log`, `playwright.log`, `yt_dlp.log`).
   - Отображение размера файла, даты модификации и общего количества строк.

2. **Структурированный табличный просмотр:**
   - Парсинг структурированных JSON записей и текстовых лог-строк.
   - Фильтрация по уровням важности (CRITICAL, ERROR, WARNING, INFO, DEBUG).
   - Быстрый полнотекстовый поиск по сообщению, стеку исключений или имени компонента.
   - Фильтр по модулям и компонентам системы (например, `[InternalApp]`, `[Router]`, `[SQLite]`).
   - Детальный инспектор записи со стеком вызовов (Traceback) и быстрым копированием.

3. **Интеллектуальный аудит и AI Диагностика:**
   - Расчет индекса стабильности работы (Health Score).
   - Кластеризация повторяющихся ошибок и аномалий с группировкой похожих инцидентов.
   - Формирование практических рекомендаций по устранению выявленных проблем.

4. **Аналитика и временная шкала (Timeline):**
   - График распределения интенсивности событий по времени с цветовым разделением ошибок, предупреждений и информационных сообщений.
   - Топ наиболее активных компонентов.

5. **Live Stream и Терминальный вывод (Tail):**
   - Потоковое отслеживание логов в реальном времени с автоматической прокруткой.
   - Возможность очистки и выгрузки (экспорта) файлов логов.

## Роутер API

- `GET /api/v1/app_logs/files` — список доступных файлов логов в `%APPDATA%\AI-Windows-Admin\logs`.
- `GET /api/v1/app_logs/records` — выборка и фильтрация структурированных записей.
- `GET /api/v1/app_logs/tail` — потоковый хвост строк лог-файла.
- `GET /api/v1/app_logs/download` — скачивание файла лога.
- `POST /api/v1/app_logs/clear` — очистка лог-файла.
- `POST /api/v1/app_logs/diagnose` — AI диагностика и кластеризация ошибок.

## Архитектура модуля

```text
├── index.html                  # Разметка, фильтры, контейнеры 5 режимов отображения
├── main.js                     # Главный оркестратор (248 строк), экспорт в window.initAppLogsTab
├── README.md                   # Документация модуля на русском языке
├── common/
│   └── ui_utils.js             # Реактивное состояние state, экранирование HTML, toast-нотификации
├── panel_files/
│   └── panel.js                # Селектор файлов логов, бейджи ошибок, очистка одного/всех файлов
├── panel_table/
│   └── panel.js                # Таблица записей, выпадающий список компонентов, модалка AIModalDialog
├── panel_audit/
│   └── panel.js                # AI Диагностика, Health Score, рекомендации и кластеры сбоев
├── panel_timeline/
│   └── panel.js                # Интерактивная временная шкала (Timeline-гистограмма), топ модулей
├── panel_tail_raw/
│   └── panel.js                # Live Tail терминал, просмотр сырого файла, фоновый Live Stream опрос
└── panel_actions/
    └── panel.js                # Быстрые пресеты, сброс фильтров, экспорт (CSV/JSON/Markdown), переключение видов
```

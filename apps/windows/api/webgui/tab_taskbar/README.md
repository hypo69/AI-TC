# 📌 Панель управления Taskbar & Window Management (`tab_taskbar`)

**Статус:** ✅ Активен  
**Язык:** Русский  
**Автор:** hypo69  

---

## 📋 Описание

Интерактивная панель веб-интерфейса для управления панелью задач Windows 10/11, активными окнами рабочего стола, закрепленными приложениями, индикаторами выполнения `ITaskbarList3` и историей изменений с поддержкой отката Rollback в telemetry.db.

---

## 🎛️ Функционал

1. **Мониторинг:** Реальное отображение габаритов панели задач, выравнивания (Win11 Left/Center), количества открытых окон и активного окна переднего плана.
2. **Управление окнами:** Таблица окон верхнего уровня рабочего стола с фильтрацией по заголовку и процессу. Быстрые действия: Активация (Focus), Сворачивание, Разворачивание, Восстановление, Закрытие (`WM_CLOSE`), а также пакетные операции.
3. **Настройки панели:** Настройка выравнивания значков, режима поиска, отображения виджетов, Copilot, Task View, бейджей и автоскрытия с возможностью перезапуска Explorer.
4. **Закрепленные приложения:** Просмотр ярлыков и форма запуска программ (с поддержкой UAC Elevation).
5. **ITaskbarList3 UX:** Эмуляция прогресс-бара и оверлеев на кнопках окон.
6. **Command Registry Explorer:** Каталог 260 системных команд Control Plane с фильтрацией по рискам и интерактивным выполнением.

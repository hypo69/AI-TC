# 🧩 Вкладка управления плагинами (`tab_plugins`)

**Статус:** ✅ Активен  
**Язык:** Русский  
**Автор:** hypo69  

---

## 📋 Описание

Интерактивная панель управления плагинами, инструментами агентов и фоновыми сервисами AI Windows Admin.
Позволяет на лету активировать/деактивировать плагины, редактировать параметры конфигурации через динамические формы, выполнять специальные действия (Actions) и просматривать журнал выполнения.

---

## 🏗 Архитектура модулей

```
tab_plugins/
├── index.html                  # Разметка вкладки, сайдбара плагинов, форм и консоли
├── main.js                     # Корневой скрипт-оркестратор (инициализация, регистрация на window)
├── common/
│   └── ui_utils.js             # Утилиты уведомлений и определения пользовательского/админского интерфейса
├── panel_list/
│   └── panel.js                # Загрузка каталога плагинов, бейджи активных, поиск и фильтрация
├── panel_details/
│   └── panel.js                # Инспекция выбранного плагина, тумблер включения/выключения, сохранение настроек
├── panel_actions/
│   └── panel.js                # Генерация кнопок действий (Actions) и их отправка на сервер
├── panel_config_fields/
│   └── panel.js                # Динамический рендеринг полей настроек (select, switch, number, list, text)
└── panel_console_nav/
    └── panel.js                # Консоль журнала плагина и синхронизация пунктов меню в шапке хоста
```

---

## 🎛️ Функционал

1. **Каталог плагинов:** Разделение на системные и пользовательские плагины, счетчики активных расширений.
2. **Динамическая конфигурация:** Автоматическое построение формы настроек по схеме `fields` плагина с сохранением в JSON.
3. **Действия (Actions):** Запуск встроенных процедур плагинов с интерактивным запросом обязательных параметров.
4. **Консоль логов:** Логирование сетевых запросов и ответов сервера в реальном времени.
5. **Интеграция с навигацией:** Автоматическое отображение/скрытие пунктов меню при переключении статуса активности.

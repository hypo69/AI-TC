# 🔬 Вкладка: Исследования Телеметрии (`tab_telemetry_research`)

Пользовательский интерфейс для аналитического исследования данных телеметрии системы и оборудования в составе платформы AI-Windows-Admin.

---

## 🏗 Архитектура модулей

```
tab_telemetry_research/
├── index.html                  # Разметка вкладки, карточек KPI, графиков и таблиц
├── main.js                     # Корневой скрипт-оркестратор (инициализация, координация runResearch)
├── common/
│   └── ui_utils.js             # Экспорт JSON отчета и открытие автономного дашборда
├── panel_sources/
│   └── panel.js                # Выбор доступных файлов и источников логов телеметрии
├── panel_kpi_hypotheses/
│   └── panel.js                # Сводные KPI метрики здоровья и карточки системных гипотез
├── panel_correlations_charts/
│   └── panel.js                # Матрица корреляций Пирсона и интерактивные графики Chart.js
├── panel_anomalies_devices/
│   └── panel.js                # Список выявленных аномалий и статус оборудования / флаппинга
└── panel_records/
    └── panel.js                # Таблица сырых записей телеметрии с пагинацией и полнотекстовым поиском
```

---

## 📌 Функциональность

- **Анализ временных рядов**: интерактивная визуализация графиков CPU, RAM, GPU, дискового I/O и температур.
- **Проверка системных гипотез**: карточки гипотез (термостресс, давление на память, флаппинг устройств).
- **Матрица корреляций**: расчет коэффициентов корреляции Пирсона между всеми парами системных метрик.
- **Детекция аномалий**: выявление критических всплесков нагрузки и сбоев устройств.
- **Интерактивные таблицы**: пагинированный просмотр и поиск по сырым записям телеметрии.
- **Экспорт отчетов**: скачивание отчетов в JSON или открытие автономного HTML-дашборда.

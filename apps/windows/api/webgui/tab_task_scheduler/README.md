# ⏱️ Вкладка Планировщика задач Windows (Task Scheduler Tab)

Модуль веб-интерфейса для мониторинга, управления заданиями и ведения журнала истории Windows Task Scheduler.

---

## 🚀 Возможности
- Просмотр счетчиков задач (всего, готовы к запуску, выполняются, отключены).
- Таблица задач с фильтрацией и поиском по имени или пути.
- Быстрые действия: немедленный запуск (`schtasks_run`) и включение/отключение (`schtasks_enable` / `schtasks_disable`).
- **Тумблер журнала истории задач:** Включение и выключение канала `Microsoft-Windows-TaskScheduler/Operational` в реальном времени.
- Информационный баннер при отключенном журнале истории задач для оперативной диагностики незапускающихся задач.

---

## 📡 REST API Интеграция
- `GET /api/task-scheduler/summary` — получение сводки задач и статуса истории.
- `GET /api/task-scheduler/history-status` — текущий статус активности журнала истории задач.
- `POST /api/task-scheduler/history-status` — включение/выключение журнала истории задач (`{"enabled": true/false}`).
- `POST /api/task-scheduler/action` — запуск или изменение состояния отдельного задания.

---

## 🛠️ Файловая структура
- `index.html` — разметка вкладки (карточки метрик, панель действий, тумблер истории, таблица задач).
- `main.js` — клиентский модуль: инициализация, поллер, переключение тумблера, фильтрация и вызовы API.
- `README.md` — документация вкладки.

# Вкладка бенчмарка производительности дисков (DiskSpd / CrystalDiskMark)

## Описание
Интерактивный модуль измерения скорости чтения и записи дисковой подсистемы (NVMe SSD, SATA SSD, HDD, флеш-накопители) с использованием официального консольного инструмента **Microsoft DiskSpd**.

## Архитектура модулей WebGUI
В соответствии со стандартами рефакторинга и лимитом строк (<= 500 строк) логика интерфейса разделена на изолированные панели:
- `common/ui_utils.js` — утилиты экспорта и копирования результатов в Markdown.
- `panel_engine_targets/panel.js` — проверка доступности утилиты DiskSpd и обнаружение накопителей/разделов.
- `panel_runner_progress/panel.js` — запуск профилей бенчмарка, отслеживание фоновой задачи и отмена.
- `panel_results_chart/panel.js` — рендеринг таблицы результатов CDM и динамического графика Chart.js.
- `panel_history/panel.js` — история замеров скорости, удаление записей.
- `main.js` — главный координатор инициализации, связывающий события и регистрирующий поллер.

## Особенности бэкенда
1. **Движок**: `diskspd.exe` (располагается в `bin/diskspd/diskspd.exe` или загружается автоматически).
2. **Безопасность**: Запись и чтение производятся исключительно на изолированном временном файле `diskspd-test.dat` в безопасной директории `AI-Windows-Admin-benchmark` или `data/benchmark`, с автоматической очисткой после теста.
3. **История**: Результаты измерений фиксируются в локальной SQLite базе данных (`data/storage_benchmarks.db`).

## Поддерживаемые профили
- `SEQ1M Q8T1`: Последовательный доступ, блок 1 MiB, очередь 8, поток 1.
- `SEQ1M Q1T1`: Последовательный доступ, блок 1 MiB, очередь 1, поток 1.
- `RND4K Q32T16`: Случайный доступ, блок 4 KiB, глубина очереди 32.
- `RND4K Q1T1`: Случайный доступ, блок 4 KiB, глубина очереди 1.

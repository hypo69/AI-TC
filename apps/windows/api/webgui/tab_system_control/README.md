# Вкладка System Logs & Activity Center (Журналы событий и активность)

**Путь:** `apps/windows/api/webgui/tab_system_control/`

## Описание
Вкладка **System Logs & Activity Center** предоставляет интерфейс для мониторинга потока системных событий Windows, работы с каналами логов, семантического RAG-поиска, аудита аномалий, анализа инцидентов и просмотра истории операций.

## Основные возможности
- Мониторинг потока событий в реальном времени (Live Events Stream).
- Интеллектуальный аудит журнала (Smart Digest) с кластеризацией и дедупликацией.
- Семантический RAG-поиск по журналам событий без расхода токенов LLM.
- Детекция каскадных сбоев и цепочек инцидентов.
- Мониторинг жизненного цикла питания и аптайма ОС (Power Lifecycle & Boot History).
- **Специализированная панель журналов и безопасности Microsoft Defender (Defender Events)**: мониторинг статуса защиты, версий сигнатур и движка, истории обнаружения угроз (1006/1116), блокировок Controlled Folder Access (1123/1124) и Exploit Guard / Attack Surface Reduction (1125/1126), быстрое сканирование и обновление баз.
- **Панель поведенческой форензики и активности (Forensics & UserAssist)**: хронологический таймлайн переключения активных окон, время бездействия пользователя, аудит обращений к веб-камере и микрофону, история запусков и времени в фокусе программ из реестра Windows (UserAssist ROT13) с переключателями суб-вкладок.
- **Панель троттлинга процессора и стабильности ядра (Kernel & Throttling Diagnostics)**: детекция аппаратного термического троттлинга PROCHOT, лимитов энергопотребления PL1/PL2, анализ задержек DPC/ISR в реальном времени, статус шины PCIe GPU и архив дампов BSOD (Minidump).
- Контекстный анализ причин ошибок с рекомендациями ИИ.

## Модульная архитектура (директории panel_*)

В соответствии с инженерным стандартом лимита строк (до 500 строк на файл) монолитный `main.js` разделен на изолированные модули:

```
tab_system_control/
├── common/
│   └── ui_utils.js              # Графические утилиты (XSS escape, formatTime, severity badges, ресайзеры)
├── panel_summary/
│   └── panel.js                 # Сводный дашборд сбоев: BSOD, Kernel-Power, ошибки драйверов, аномалии
├── panel_event_logs/
│   ├── channel_tree.js          # Сканирование каналов, тултипы и кэш браузера
│   ├── modal.js                 # Модальное окно деталей события и AI-диагностика
│   └── panel.js                 # Таблица событий, фильтрация и компактный вид
├── panel_smart_digest/
│   ├── panel.js                 # Smart Digest аудит, кластеризация и дедупликация шаблонов
│   └── incidents_timeline.js    # Каскадные сбои, цепочки инцидентов и Activity Heatmap
├── panel_rag/
│   ├── rag_db.js                # Локальное хранилище IndexedDB / LocalStorage чанков
│   └── panel.js                 # UI поиска, индексация и отображение результатов
├── panel_power_lifecycle/
│   ├── modals.js                # Модальные окна сессий питания и сырого XML
│   └── panel.js                 # Непрерывный аптайм, история загрузок и выключений
├── panel_defender_logs/
│   └── panel.js                 # События Microsoft Defender, блокировки CFA/ASR, сканирование
├── panel_forensics/
│   └── panel.js                 # Форензика активности окон, простой, UserAssist ROT13, сенсоры
├── panel_throttling/
│   └── panel.js                 # Троттлинг процессора, PROCHOT, PL1/PL2, задержки DPC/ISR, дампы BSOD
├── panel_activity/
│   └── panel.js                 # Журнал действий администратора в приложении
├── index.html                   # Разметка интерфейса вкладки
└── main.js                      # Корневой оркестратор (роутинг, таймеры, переключение источников)
```

# Вкладка управления навыками (Agent Skills Tab)

Модуль веб-интерфейса для инспекции, создания, тестирования, настройки и сборки переиспользуемых навыков агентов (Agent Skills) в среде AI Windows Admin, Gemini CLI и Antigravity.

---

## 📋 Основные возможности

1. **Реестр и каталог навыков**:
   - Автоматическое обнаружение навыков в директориях `.agents/skills`, `.gemini/skills`, `~/.agents/skills` и `skills`.
   - Режимы отображения: адаптивные карточки и компактная таблица.
   - Быстрый поиск по названию, описанию (EN/RU) и фильтры по компонентам (скрипты, справочники, скомпилированные `.skill`).
2. **Создание навыков (3 режима)**:
   - **🧙‍♂️ Пошаговый мастер (Wizard)**: Метаданные, структурированные блоки инструкций, генерация `SKILL.md` и `README.md`, подключение исполняемых скриптов `scripts/main.py` и справочников `references/guide.md`.
   - **🤖 AI-генератор (Natural Language to Skill)**: Генерация полноценного навыка по описанию задачи на естественном языке с вызовом модели через API.
   - **📦 Готовые шаблоны (Presets)**: Готовые паттерны (CLI & Python Tool, REST API Connector, Data Analyzer, AI Persona, Health Monitor, Doc Generator).
3. **Инспектор и песочница (Sandbox)**:
   - Просмотр и редактирование `SKILL.md`, `README.md`, метаданных и JSON Contract.
   - Интерактивное тестирование навыка в песочнице (Sandbox) с вызовом агента.
   - Сборка навыка в стандартизированный дистрибутив архива `.skill`.
   - Безопасное удаление навыка.

## 🏛 Модульная архитектура (ES6 Modules)

```
tab_skills/
├── common/
│   └── ui_utils.js              # Экранирование HTML, форматирование байт, безопасный apiFetch
├── panel_catalog/
│   └── panel.js                 # Каталог навыков, карточки, табличный вид, фильтрация и счетчики
├── panel_wizard/
│   └── panel.js                 # Пошаговый мастер создания навыка (шаги 1..4), предпросмотр, валидация
├── panel_ai_generator/
│   └── panel.js                 # Генерация навыка через модель ИИ по естественному запросу
├── panel_presets/
│   └── panel.js                 # Каталог готовых шаблонов навыков и применение в мастер
├── panel_details_modal/
│   └── panel.js                 # Инспектор навыка: просмотр, сохранение, Sandbox-тестирование, экспорт .skill
├── index.html                   # Разметка интерфейса, мастеров и модальных окон
├── main.js                      # Компактный оркестратор SkillsTabManager (<= 500 строк)
└── README.md                    # Документация модуля
```

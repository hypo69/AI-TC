# Вкладка управления пользователями (User Management Component)

Административный модуль веб-интерфейса для управления локальными и удаленными учетными записями, ролями доступа, аутентификацией, привязками Telegram и аудита директорий хранения.

---

## 📋 Основные возможности

1. **Каталог учетных записей**:
   - Быстрый просмотр пользователей с аватарами, ролями (`admin`, `user`, `guest`) и статусами (`active`, `blocked`).
   - Прямое табличное редактирование ролей и статусов через выпадающие списки.
   - Режим строчного редактирования (Inline Edit) по двойному клику или кнопке (Enter — сохранить, Esc — отмена).
   - Фильтры по ролям, статусам и живой поиск по имени, email и Telegram с debounce 300мс.

2. **Административные операции**:
   - Создание нового пользователя с генератором безопасных паролей (12 символов).
   - Редактирование профиля в модальном окне.
   - Сброс и принудительная смена пароля.
   - Просмотр детального досье: ID, email верификация, привязка Telegram, UI-тема, голос TTS, системная инструкция ИИ, разрешения.
   - Безопасное удаление аккаунтов с защитой учетной записи Root (ID: 1).

3. **Мертвые директории пользователей (Orphaned Directories)**:
   - Автоматический аудит папок в хранилище `data/users/`, не привязанных к активным аккаунтам.
   - Статистика занятого места на диске и количества файлов.
   - Удаление отдельных папок или пакетная очистка всех неактивных каталогов.

# Вкладка «Жизненный цикл и сессии питания» (`tab_power_lifecycle`)

## 📋 Описание
Интерактивный дашборд и аналитический центр для мониторинга истории перезагрузок, выключений и жизненного цикла питания операционной системы Windows.

Позволяет реконструировать полноценные сессии работы ОС (**Power Sessions**), определять истинных инициаторов выключения (пользователь, процесс, служба, WMI-запрос), фиксировать внезапные отключения питания (**Kernel-Power 41 / EventLog 6008**) и системные сбои (**BSOD / BugCheck 1001**).

## 🔑 Ключевые отслеживаемые события Windows Event Log

| Event ID | Провайдер | Значение и назначение |
|---|---|---|
| **1074** | `User32` | Кто/какой процесс инициировал shutdown/restart, тип (Restart, PowerOff), код причины и комментарий |
| **13** | `Kernel-General` | ОС начала процедуру завершения работы |
| **6006** | `EventLog` | Служба Event Log корректно остановлена (маркер чистого штатного выключения) |
| **6008** | `EventLog` | Предыдущее выключение было неожиданным |
| **41** | `Kernel-Power` | Критический сбой: система перезапустилась без корректного shutdown (потеря питания / зависание / BSOD) |
| **12** | `Kernel-General` | Запуск ядра операционной системы (Boot) |
| **6005** | `EventLog` | Служба Event Log запущена (ОС готова к работе) |
| **6009** | `EventLog` | Windows записала информацию о версии ядра при загрузке |
| **1001** | `WER-SystemErrorReporting` | Аварийная перезагрузка вследствие bugcheck / BSOD |
| **19** | `WindowsUpdateClient` | Успешно установлено обновление Windows Update |
| **42 / 107** | `Kernel-Power` | Переход в спящий режим (Sleep) и пробуждение (Wake) |

## 🛠️ API Эндпоинты

- `GET /api/v1/power/summary` — Сводные метрики аптайма, количества сессий и сбоев.
- `GET /api/v1/power/sessions` — Список реконструированных сессий с пагинацией и фильтрами.
- `GET /api/v1/power/sessions/{session_id}` — Детали конкретной сессии и цепочка событий.
- `GET /api/v1/power/events` — Список сырых нормализованных событий питания.
- `POST /api/v1/power/rebuild` — Принудительное сканирование журналов событий и перестроение сессий.

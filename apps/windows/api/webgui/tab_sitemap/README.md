# Вкладка Карты Сайта WebGUI (`tab_sitemap`)

## 📋 Описание
Интерактивная карта сайта (Sitemap) веб-интерфейса AI Windows Admin (`apps/windows/api/webgui`).
Представляет собой централизованный каталог всех доступных вкладок интерфейса с подробным описанием их назначения, перечнем доступных функций и настроек, а также динамическим статусом активности на основе конфигурации меню (`tc_menu_config.json`).

## 📁 Структура каталога
- `index.html`: Разметка интерфейса карты сайта (счетчики статистики, поиск, фильтры по статусам и категориям, контейнер карточек).
- `main.js`: Модуль управления логикой (загрузка данных, динамическое сопоставление со структурой меню, живая фильтрация, обработчики переходов).
- `sitemap_data.json`: Реестр метаданных всех вкладок (идентификаторы, иконки, категории, описания, списки функций).
- `generate_sitemap_data.py`: Вспомогательный скрипт генерации/синхронизации `sitemap_data.json`.
- `README.md`: Настоящая документация.

## 🚀 Архитектурные соглашения и стандарты
1. **Именование директорий вкладок:** Все каталоги вкладок веб-интерфейса обязаны строго следовать шаблону `tab_<tab_id>` (например: `tab_about_system`, `tab_defender_firewall`, `tab_sitemap`).
2. **Определение активности:** Статус вкладки (Активна в верхнем меню / Активна в боковом меню / Скрыта) вычисляется динамически при каждом открытии карты сайта на основе параметров `"visible": true/false` из `config_menues/tc_menu_config.json`.
3. **Отсутствие хардкода стилей:** Весь интерфейс реализован строго через CSS-переменные дизайн-системы и классы Bootstrap 5 (`bg-body`, `bg-body-tertiary`, `border-secondary-subtle`, `text-body`, `badge`, `btn-outline-primary`).
4. **Мгновенный переход:** Нажатие на кнопку «Открыть вкладку» вызывает глобальный диспетчер `window.switchTab(tabId)`, мгновенно отображая нужный интерфейсный раздел.

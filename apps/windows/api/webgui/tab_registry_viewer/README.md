# 🗝️ Вкладка просмотра и редактирования реестра (`tab_registry_viewer`)

## Назначение
Интерактивный графический обозреватель и редактор системного реестра Windows для безопасного аудита параметров, конфигурации служб, автозагрузки, программного обеспечения и групповых политик с поддержкой резервного копирования и отката.

---

## 🏗 Архитектура модулей

```
tab_registry_viewer/

```

## Возможности
- Навигация по всем основным корневым веткам (`HKLM`, `HKCU`, `HKCR`, `HKU`, `HKCC`).
- Быстрые системные закладки (Автозагрузка Run/RunOnce, Установленные программы x64/x86, Службы, Переменные среды, История UserAssist, Политики).
- Просмотр подразделов (Subkeys) и параметров с типами данных (`REG_SZ`, `REG_DWORD`, `REG_EXPAND_SZ`, `REG_MULTI_SZ`, `REG_BINARY`, `REG_QWORD`).
- Интерактивный AI-анализ назначения любого ключа и параметра через `AITableModal`.
- Безопасное создание, редактирование и удаление параметров с автоматической точкой восстановления.

## API Эндпоинты
- `GET /api/registry/bookmarks` — список быстрых системных закладок.
- `GET /api/registry/key?hive=...&path=...` — чтение подразделов и параметров ключа.
- `POST /api/registry/key` / `DELETE /api/registry/key` — управление разделами реестра.
- `POST /api/registry/value` / `DELETE /api/registry/value` — управление параметрами реестра.
- `GET /api/registry/backups` / `POST /api/registry/restore` — резервные копии и откат.

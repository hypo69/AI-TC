# 🎬 Вкладка «Сценарии» (Test Computer Scenarios & Autonomous AI Agent)

## Назначение
Вкладка **«Сценарии»** (`tab_scenarios`) является главным стартовым хабом интерфейса Test Computer (`/tc` и `/apps`) для автоматизированной экспресс-диагностики, прогона смоук-тестов и автономного решения цепочек системных задач с использованием **LangChain ReAct Agent** и **WikiLLM Toolbox**.

---

## Ключевые возможности

1. **Автономное решение цепочек задач (UniversalLangChainAgent):**
   - Прямой потоковый диалог через SSE (`POST /api/v1/diagnostics/chat`).
   - Модель автономно выбирает инструменты из `WikiLLM Toolbox` или синтезирует новые PowerShell-зонды на лету через вызов `create_custom_tool`.
   - Прозрачный матричный терминал рассуждений (`[MATRIX REASONING]`) в реальном времени с бейджами `THINK`, `TOOLBOX`, `SYNTHESIS`, `TELEMETRY`, `COMPLETE`.
2. **3 динамических вопроса хоста:**
   - Генерация актуальных контекстных вопросов о состоянии операционной системы через `POST /api/v1/diagnostics/suggest-questions`.
   - Кнопка «🔄 Другие вопросы» для мгновенной генерации альтернативных гипотез.
   - Запуск расследования в один клик.
3. **Безопасное интерактивное исполнение команд на хосте:**
   - Все предложенные моделью команды PowerShell и CMD оформляются в интерактивные карточки с кнопками «Запустить на хосте», «Копировать» и прямым выводом stdout/stderr.
4. **Быстрая проверка (Smoke Test) и каталог экспресс-сценариев:**
   - Проверка серверного окружения, Python, доступности AI-провайдеров, свободного места на дисках и состояния логов.
   - Выдвижная панель сценариев Offcanvas с фильтрами по категориям (экспресс, логи, система, безопасность).

# Вкладка глубокого сканирования ПО и спящих программ

Интерфейс визуализации и управления глубоким аудитом установленного программного обеспечения Windows.

## 🎯 Назначение
- Запуск сканирования в различных режимах (`Quick`, `Deep`, `Forensic`, `Orphans`).
- Отображение агрегированных карточек установленного и спящего ПО (Dormant).
- Выявление осиротевших служб, задач планировщика и некорректных записей деинсталлятора.
- Просмотр всех низкоуровневых свидетельств (артефакты UserAssist, Prefetch, реестр, PE-метаданные).

## 🔌 Архитектура
- **HTML:** `index.html` (соответствие стандарту `id="panel-{panel_id}"` и `data-panel-id="{panel_id}"`).
- **JS:** `main.js` (управление состоянием, фильтрация, вызов `/api/windows/software-scanner/scan` и `/api/v1/panel/...`).

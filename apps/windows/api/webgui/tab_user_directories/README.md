# Вкладка «Пользовательские директории и хранилище» (User Directories & Storage)

## Назначение
Модуль пользовательского веб-интерфейса для мониторинга, аудита, поиска и управления персональными изолированными хранилищами пользователей платформы **AI Windows Admin** (`data/users/<user_id>/`).

## Архитектура модулей
Файлы декомпозированы по панельной архитектуре (`panel_*`) в соответствии с лимитом `<= 500` строк функционального кода (`GEMINI.md` § 4.4):

```
tab_user_directories/
├── index.html                           # Разметка интерфейса и модальных окон
├── main.js                              # Модульный оркестратор вкладки (< 160 строк)
├── README.md                            # Описание модуля на русском языке
├── common/
│   └── ui_utils.js                      # Реактивное состояние, экранирование HTML, алерты, иконки
├── panel_summary/
│   └── panel.js                         # Метрики общего объема, количества файлов и осиротевших каталогов
├── panel_users/
│   └── panel.js                         # Список пользователей, квоты, роли и переключение проводника
├── panel_files/
│   └── panel.js                         # Таблица файлов, модальное окно предпросмотра, скачивание и удаление
└── panel_orphaned/
    └── panel.js                         # Сканирование и безопасная очистка осиротевших каталогов
```

## Возможности
1. 🔍 **Поиск и фильтрация**:
   - Мгновенный поиск по имени пользователя, email и именам файлов в хранилище.
   - Фильтрация по расширениям файлов (`.pdf`, `.txt`, `.json`, `.csv`, `.png` и др.).
2. 📁 **Интерактивный файловый проводник**:
   - Двухпанельный интерфейс: список пользователей с дисковыми квотами слева, дерево и таблица файлов справа.
   - Детализация каждого файла: размер, дата изменения, расширение, путь и подпапка (`files`, `rag`, `profile`, `temp`).
3. 📊 **Статистика и аналитика**:
   - Общий объем данных хранилища на диске.
   - Прогресс-бары использования квот для каждого пользователя.
   - Распределение файлов по типам и разделам.
4. 🛠️ **Действия с файлами**:
   - Встроенный безопасный предпросмотр текстовых файлов, кода, JSON и изображений.
   - Скачивание файлов напрямую через браузер.
   - Удаление файлов и каталогов.
   - Автоматическое обнаружение и пакетная очистка осиротевших (мертвых) директорий.

## Интеграция
- Точка входа: `window.initUserDirectoriesTab()`
- Активация: `window.activateUserDirectoriesTab()`
- Режим скриптов: ES6-модули (`type="module"`).

# Вкладка «Серверы MCP» (Model Context Protocol)

## Описание
Вкладка **«Серверы MCP»** (`tab_mcp`) представляет собой административную панель для регистрации, конфигурирования, инспекции и тестирования серверов протокола Model Context Protocol (MCP) в AI Windows Admin. Поддерживает работу с локальными процессами `stdio` (npx, uvx, python) и удаленными эндпоинтами (`sse`, `streamable_http`).

## Архитектура модулей
Код декомпозирован по панельной схеме (`panel_*`) в соответствии с лимитом `<= 500` строк (`GEMINI.md` § 4.4):

```
tab_mcp/
├── index.html                           # Разметка интерфейса и модальных окон
├── main.js                              # Модульный оркестратор вкладки (< 160 строк)
├── README.md                            # Описание архитектуры на русском языке
├── common/
│   └── ui_utils.js                      # Реактивное состояние, экранирование HTML, клиент apiFetch
├── panel_servers/
│   └── panel.js                         # Сетка карточек и таблица серверов, тулбар поиска и фильтрации
├── panel_modal_server/
│   └── panel.js                         # Модальный редактор серверов, пресеты (Playwright, SQLite, Memory и др.)
└── panel_test_tools/
    └── panel.js                         # Тестирование соединения (latency ms) и общий каталог инструментов (Tools)
```

## Основной функционал
1. **Реестр серверов MCP**: Отображение в виде адаптивных карточек или компактной таблицы с быстрыми тумблерами активности (ON/OFF).
2. **Шаблоны конфигураций (Presets)**: Готовые пресеты для Playwright (веб-браузер), Filesystem (файловая система), Memory (граф знаний), SQLite (инспекция БД), Fetch (веб-запросы) и SSE.
3. **Экспресс-тестирование**: Проверка сетевого взаимодействия или запуска процесса с замером времени отклика (latency) и автоматическим обнаружением экспортируемых функций (Tools).
4. **Каталог инструментов**: Централизованная сводка всех инструментов с подробными JSON-схемами параметров (`args_schema`).

## Интеграция
- Точка входа: `window.initMcpTab()`
- Экземпляр менеджера: `window.mcpTab`
- Класс: `window.McpTabManager`
- Режим скриптов: ES6-модули (`type="module"`).
